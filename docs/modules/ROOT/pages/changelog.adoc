== 2026-11-13

=== Theme contrast

The docs theme uses the site mark, Sora, and the same slate and violet as userdata.cloud. The violet is a step darker in light mode and a step lighter in dark mode so body links and the current nav item clear the contrast check.

=== Team docs link

* `@antora-supplemental/related-docs` lists the member site on every public page. Detail: xref:changelog-details/history/2026-11-13 - team docs link.adoc[team docs link].
* The link target is https://team.docs.userdata.cloud/[team.docs.userdata.cloud]. Sign-in is Cloudflare Access for members of the userdata-cloud GitHub organization.
* The market plan stays on that site. This hub does not publish those pages.

The public docs hub opens with a portal and the vault component.
