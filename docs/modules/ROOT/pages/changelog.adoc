== 2026-11-13

The docs theme uses the site mark, Sora, and the same slate and violet as userdata.cloud. The violet is a step darker in light mode and a step lighter in dark mode so body links and the current nav item clear the contrast check.

== 2026-11-12

The public docs hub opens with a portal and the vault component.

=== Hub and vault component
* This repository publishes the organization docs with Antora.
* The vault repository contributes the `vault` component, including the page for what to build first.

=== Docs hostname
* The hub is served at https://docs.userdata.cloud/. The DNS record is not proxied, so GitHub Pages can issue the certificate.
